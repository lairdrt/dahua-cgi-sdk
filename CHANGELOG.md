# v1.0

Here's what I think v1.0 should accomplish

Not 100 endpoints.

Not every CGI command.

Instead:

- A clean, stable DahuaClient
- A solid transport layer
- A reusable parser framework
- One fully implemented subsystem (media)
- A handful of well-designed domain objects
- Good documentation
- Tests
- A release that I'd be comfortable telling someone else to use

If we achieve that, we've built a platform.

Everything else is incremental.
